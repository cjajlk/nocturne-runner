# Nocturne Runner

Prototype v0.9.2 d'un endless runner dans une cité néon.

## Jouer

Ouvrir `index.html` dans Chrome ou Edge, ou servir le dossier avec un serveur local. Aucun téléchargement externe n'est nécessaire.

- Flèches gauche/droite : changer de voie.
- Flèche haut ou espace : sauter.
- Flèche bas : glisser.
- B : propulsion, une activation par course.
- Échap : pause.
- Mobile : gestes directionnels et bouton propulsion.

## Fonctionnalités

Corridor 3D, quatre types d'obstacles, cristaux, portefeuille local, atelier, missions et options. Planche néon sous les pieds et compagnon robot pendant le bonus aimant.

La progression est sauvegardée dans le navigateur. Musique et variantes de personnages sont prévues.

Voir `README.txt` pour les règles, améliorations et vérifications du prototype.
