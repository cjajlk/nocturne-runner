# Assets v0.10

Visuels originaux générés avec l’outil intégré ImageGen, sur fond transparent. Les fichiers PNG sont conservés sans retouche ; sprites.js décrit les zones utilisées pour les poses.

- nova-sheet.png : six poses de Nova (debout, deux pas de course, saut, glissade, debout).
- cat-sheet.png : quatre poses du chat néon (repos, capture, queue levée, retour au repos).
- sprites.js : coordonnées de lecture de chaque pose.

## Prompt Nova

Use case: stylized-concept. Asset type: transparent game sprite sheet. Create ONE sprite sheet of NOVA, an adult female cyberpunk runner, for Nocturne Runner. Exactly SIX equal cells in a 3-column 2-row grid, no grid lines. Each cell has one isolated full body character entirely inside it with generous transparent margins. All poses are viewed FROM BEHIND, consistent character design, camera at waist height slightly elevated. Top row left: standing upright with both feet down (hoverboard stance, no board). Top row middle: running left leg forward. Top row right: running right leg forward. Bottom row left: airborne jumping knees bent. Bottom row middle: crouching low sliding forward seen from behind. Bottom row right: upright standing rear view again. Nova wears a black fitted functional jacket and dark cargo trousers with bright cyan circuit stripes, violet accents, cyan sneaker soles, violet short ponytail. Athletic realistic adult proportions, fully clothed. Detailed polished stylized 3D render with strong silhouette like a dark futuristic endless runner. CONSISTENT SCALE for upright poses and foot baseline within every cell; slide stays at baseline and is shorter. Canvas landscape, each cell tall enough for body. TRUE transparent background including all gaps, no backdrop, no shadow disk, no lettering, no watermark, no other characters.

## Prompt chat néon

Use case: stylized-concept. Asset type: transparent game sprite sheet. Create ONE sprite sheet of a cute small cyber CAT companion for a neon endless runner. Exactly FOUR equal square cells in one horizontal row, no grid lines or lettering. Same single cat in all cells, entire body inside each cell with wide transparent margins. Black graphite body with violet fur/armor highlights, turquoise glowing eyes, cyan ear edges, violet paws, long flowing tail. Friendly compact round head, pointy cat ears, clear cat silhouette, consistent design, polished detailed stylized 3D game render. Three-quarter rear-side view facing left toward the runner, face slightly visible. Frames from left: floating idle paws relaxed; floating paws reaching forward to catch a crystal (NO crystal depicted); floating tail raised; floating paws returning to rest. No wings, no collar text. True transparent background between and around all cats. No ground, no shadow, no text, no environment, no UI.
