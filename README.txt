NOCTURNE RUNNER V1 — version de travail

Ouvrir index.html dans Chrome/Edge, de préférence à la même adresse de serveur local que précédemment.
Les bonus s'activent avec 1 / 2 / 3 / 4 (B pour le vol), ou les boutons tactiles.
Les ramassages vont dans le stock : préparer les unités dans Inventaire avant une course.
Les gains sont enregistrés pendant la course. Ne pas effacer les données du navigateur.

Voir README.md et V1-STATUS.md pour les règles, la sauvegarde, les tests et les travaux restants.
